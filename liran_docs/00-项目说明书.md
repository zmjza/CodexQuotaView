# CodexQuotaView 项目说明书

## 项目定位

CodexQuotaView 是 QuotaView 的开源二次开发版本，是面向 Codex 用户的紧凑型本地额度、Token 活动和会话状态桌面工具。产品同时提供 macOS 菜单栏应用和 Windows 系统托盘应用，并保持两端功能语义和视觉体验一致。

## 当前事实基线

- Git HEAD：`d3487bd20435ce6b6041423431672d4764c36d98`。
- 上游稳定生产基线：QuotaView `0.3.5 Build 5`，包含主面板、Widget、Activity Hook、Metal 流体球、Sparkle 和用量概览。
- 当前仓库只有 macOS Swift/Xcode 实现，尚无 Windows 工程。
- 当前 CI 只有 `macos-26` 上的 `swift test`。
- `AGENTS.md` 与 `docs/pitfalls/` 存在未提交的长期避坑知识库改动，属于受保护工作区内容。

## 目标用户

- 需要随时查看 Codex 套餐、额度、Token 和重置时间的个人用户。
- 希望从菜单栏或托盘快速确认 Codex 活动状态的开发者。
- 不愿部署服务器或向第三方服务上传 Codex 使用数据的本地优先用户。

## 1.0.0 目标

1. 完成品牌、应用身份和发布资产迁移。
2. 保持 macOS 稳定生产能力，并生成 Apple Silicon/Intel Universal 安装包。
3. 使用 WinUI 3、.NET 8 和 Windows App SDK 建立 Windows x64 原生版本。
4. 两端共享 JSON Schema、Fixture、视觉 Token、状态映射和协议文档，分别使用 Swift 与 C# 实现，不引入 Rust FFI。
5. Windows 视觉以 macOS 为唯一母版，达到已确认的静态、动态和几何门槛。
6. 通过 GitHub CI/CD 生成可下载的 macOS 与 Windows 资产。

## 非目标

- 不建设账号、同步、遥测或用量代理服务器。
- 不抓取 Codex 网页，不复制用户登录凭据。
- 不接入真实额度重置消费接口。
- 不恢复已归档的 `0.3.2 Preview 1` 多任务活动岛。
- 首版不承诺 Windows ARM64。
- 不把 macOS 改造成 Electron、WebView 或跨平台网页套壳。
- 不声称 Windows 使用了 Apple Liquid Glass API；只验收最终视觉等价。

## 项目级规则例外

用户于 2026-08-14 明确要求只使用 GitHub，不使用 Gitee。该指令优先于 `AGENTS.md` 的通用双远端发布默认规则。CodexQuotaView 的源码推送、CI、CD 和 Release 均以 GitHub 为唯一远端，缺少 Gitee 不构成阻塞。

用户明确指定二开产品从 `1.0.0 Build 1` 开始。旧 QuotaView 同一 Marketing Version 递增 Build 的规则只适用于旧产品发布线，不阻止新产品身份使用 Build 1；迁移时必须同时更新 App、Widget、Helper、安装包和更新源身份。

## 交付边界

- macOS：`.app`、Universal DMG、Universal ZIP。
- Windows：x64 Setup EXE、Portable ZIP、可直接启动的 `CodexQuotaView.exe`。
- 通用：SHA-256 清单、GitHub Actions 构建证据和 GitHub Release。
- “下载即可打开”以目标平台安全策略允许的最小摩擦为准；正式公开分发需要有效 macOS Developer ID/公证和 Windows 代码签名，否则必须如实记录 Gatekeeper 或 SmartScreen 限制。

## 状态机

`待开发 → 进行中 → 内部测试通过 → 待实测 → 真机测试通过 → 已完成`

Windows 不进入“真机测试通过”，其最终平台状态为“Windows 内部测试通过”；项目整体只有在 macOS 真机、Windows 内部门禁、文档回写和发布产物均完成后才能标记“已完成”。
