# CodexQuotaView 1.0.0 需求文档

## 需求状态

- 文档状态：`Accepted`，依据为用户于 2026-08-14 的集中确认。
- 交付状态：`Planned`。
- 产品版本：`1.0.0 Build 1`。

## 品牌与产品身份

| Requirement ID | 需求 | 验收条件 |
|---|---|---|
| `CQV-BRAND-001` | 所有用户可见品牌改为 CodexQuotaView | App、窗口、托盘/菜单栏、Widget、设置、本地化和安装包无旧产品显示名 |
| `CQV-BRAND-002` | 建立独立 Bundle/Package/Windows Identity | App、Widget、Helper、测试和更新身份无意外冲突 |
| `CQV-BRAND-003` | 版本固定为 1.0.0 Build 1 | 所有目标和产物版本一致 |
| `CQV-BRAND-004` | 保留 MIT License、Git 历史和上游归属 | License、历史、README 归属可核对 |
| `CQV-BRAND-005` | 使用新的应用图标与资源命名 | 图标清晰、各尺寸完整、旧资源仅在历史文档中出现 |

## 平台与运行形态

| Requirement ID | 需求 | 验收条件 |
|---|---|---|
| `CQV-MAC-001` | 支持 macOS 14+ | 部署目标和运行验证覆盖最低版本语义 |
| `CQV-MAC-002` | 生成 arm64+x86_64 Universal 应用 | App、Widget、Helper 和 Framework 架构一致 |
| `CQV-MAC-003` | macOS 26 原生 Liquid Glass，14–15 稳定回退 | 清透/磨砂两模式均有明确平台路径 |
| `CQV-MAC-004` | 保留 SwiftUI、AppKit、Metal、WidgetKit、Sparkle 原生实现 | 无 Electron/WebView 迁移 |
| `CQV-WIN-001` | Windows 11 24H2+ x64 原生客户端 | 自包含 EXE 在干净 Runner 烟雾启动 |
| `CQV-WIN-002` | 使用 WinUI 3、.NET 8、Windows App SDK | 工程、运行时和发布清单可核对 |
| `CQV-WIN-003` | C++/WinRT + D3D11/HLSL 渲染组件 | 可编译并输出主要状态离屏帧 |
| `CQV-WIN-004` | 原生 Codex 后端优先，WSL 兼容兜底 | 两路径具有探测、选择、错误和测试证据 |
| `CQV-WIN-005` | 系统托盘和本地自包含发布 | 无需预装 .NET 或开发工具 |
| `CQV-WIN-006` | 首版不承诺 ARM64 | 文档与工作流不虚假标记 ARM64 支持 |

## 隐私、安全、更新与交付

| Requirement ID | 需求 | 验收条件 |
|---|---|---|

| `CQV-UPD-002` | Windows 使用 Velopack 更新 | 安装、便携与更新通道不混淆 |
| `CQV-CI-001` | GitHub 双平台 CI | macOS、Windows、Fixture、视觉和文档门禁均通过 |
| `CQV-CI-002` | GitHub-only 发布 | 不添加 Gitee 依赖或阻塞 |
| `CQV-REL-001` | macOS 签名、公证、Staple、Gatekeeper | 正式资产证据齐全 |
| `CQV-REL-002` | Windows Setup/Portable/EXE 与代码签名 | 资产身份、启动、哈希和签名可核对 |
| `CQV-REL-003` | GitHub Release 与回下载校验 | Tag、说明、资产、SHA-256、回下载一致 |
| `CQV-REL-004` | 最终本地可直接使用 | 不依赖自建服务器或开发环境 |

## 需求冻结边界

- 本文范围已由用户确认。新增真实消费接口、多任务活动岛、Windows ARM64、云同步或遥测必须建立新 Requirement，不得静默加入 1.0.0。
- 未确认的签名身份、Team ID、Notary 凭据和 Windows 证书只作为发布前置，不得写成现有事实。
