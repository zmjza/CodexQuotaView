## 追踪规则

1. 每个任务必须引用 `01-需求文档.md` 中的 Requirement ID。
2. 每个 Requirement 必须在模块任务、测试用例和最终验收中至少出现一次。
3. 状态只能按 `待开发 → 进行中 → 内部测试通过 → 待实测 → 真机测试通过 → 已完成` 推进；Windows 使用“Windows 内部测试通过”代替真机结论。
4. 本索引登记的是规划体系，不改变现有 `docs/specs/` 的历史事实；进入生产实现前必须同步建立 CodexQuotaView 1.0.0 的正式 SDD 规格入口。
