## 完成定义

只有以下全部成立才可把项目标记“已完成”：

1. 所有模块任务完成且有 Requirement、代码、测试和验收证据。
2. GitHub CI 必需检查全绿，双平台 Artifact 可回下载。
3. macOS 在真实 Mac 完成 `09-真机实测.md` 全部必需步骤。
4. Windows 只标记“内部测试通过”，其自动化范围完整且无伪造真机结论。
5. 正式签名、公证、安装包、SHA-256 和 GitHub Release 已验证；缺少证书时只能标记受阻，不能声称公开分发完成。
6. `AGENTS.md`、`docs/pitfalls/`、正式规格、HANDOFF、版本历史和本追踪已同步。
