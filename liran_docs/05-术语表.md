# 术语表

| 术语 | 定义 |
|---|---|
| CodexQuotaView | 本项目二开产品名称，版本从 1.0.0 Build 1 开始 |
| QuotaView | 上游开源项目及历史产品身份 |
| 主周期 | Codex 返回的主要额度窗口，不假定固定为一周 |
| Spark | 独立的 Spark 额度窗口，当前稳定实现通常按周展示 |
| Credits | Codex 额度余额；可能为有限、无限或不可用 |
| Reset Credit | 可用于立即重置符合条件周期的机会；1.0.0 仅 Demo |
| 数据可用 | 最近一次 Codex 数据获取有效，不等于额度充足 |
| Golden Image | 在固定条件下生成的视觉母版截图 |
| 感知差异 | 允许轻微抗锯齿差异的视觉相似度指标 |
| Liquid Glass | macOS 26 的系统玻璃能力；Windows 只做视觉等价实现 |
| Compact Widget Host | Windows 原生 Widget 不可行时的无边框桌面 Widget 替代宿主 |
| Native Backend | Windows 直接调用 Windows 版 Codex 本地能力的后端 |
| WSL Backend | 通过 WSL 调用 Codex 的兼容后端 |
| Hook | Codex 会话事件到本地活动状态的脱敏桥接 |
| Activity Island | 当前稳定单任务活动状态浮层，不包含归档多任务 Preview |
| Fixture | 不含真实用户敏感数据的固定协议样本 |
| Universal | 同时包含 `arm64` 与 `x86_64` 的 macOS 二进制 |
| Self-contained | Windows 包含所需 .NET 运行时，不要求用户预装 |
| 内部测试通过 | 自动化、构建、烟雾和静态/离屏验证通过，不代表真实 Windows 设备验收 |
| 真机测试通过 | Codex 在真实 macOS 环境按清单实际操作并记录证据 |
