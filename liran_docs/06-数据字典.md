# 数据字典

## 共享快照

| 字段 | 类型 | 来源/语义 | 缺失行为 | 隐私 |
|---|---|---|---|---|
| `schemaVersion` | string | 共享 Schema 版本 | 拒绝未知重大版本 | 公开 |
| `capturedAt` | UTC datetime | 快照生成时间 | 标记不可用 | 低敏 |
| `availability` | enum | available/unavailable/refreshing/error | 必填 | 公开 |
| `serviceHealth` | enum | 正常、警告、耗尽、离线、错误 | unknown | 公开 |
| `planType` | string? | 官方套餐枚举 | 显示破折号 | 低敏 |
| `primaryWindow` | quota window? | 主周期额度 | 不显示 0% | 低敏 |
| `sparkWindow` | quota window? | Spark 周期额度 | 隐藏或不可用 | 低敏 |
| `creditBalance` | decimal/string? | Credits | 破折号 | 低敏 |
| `unlimitedCredits` | bool | Credits 是否无限 | false 不能替代未知 | 低敏 |
| `resetCredits` | integer? | 可用重置机会 | 未知时不显示入口 | 低敏 |
| `recentDailyTokens` | int64? | 最近报告日 Token | 破折号 | 低敏 |
| `tokens30d` | int64? | 最近 30 日汇总 | 破折号 | 低敏 |
| `lifetimeTokens` | int64? | 当前账号累计 Token | 破折号 | 低敏 |
| `estimatedCost30d` | decimal? | 30 日成本估算 | 破折号 | 推导数据 |
| `dailyActivity` | array | UTC 日桶 | 缺失日不可伪造为零 | 低敏 |
| `sanitizedError` | code/message? | 有界错误摘要 | 不包含原始响应 | 低敏 |

## 额度窗口

| 字段 | 类型 | 约束 |
|---|---|---|
| `id` | string | 稳定语义 ID |
| `usedPercent` | number? | 0–100，有效时才存在 |
| `remainingPercent` | number? | 0–100，与 used 语义一致 |
| `resetsAt` | UTC datetime? | 不通过本地时区改变协议值 |
| `durationMinutes` | integer? | 不硬编码 5 小时/7 天 |
| `risk` | enum | normal/warning/critical/exhausted/unknown |

## Hook 事件白名单

| 字段 | 类型 | 规则 |
|---|---|---|
| `sessionHash` | string | 单向哈希，不保存原 Session ID |
| `turnHash` | string? | 单向哈希 |
| `workspaceLeafName` | string? | 只保留路径末级名称 |
| `eventType` | enum | 会话/轮次/工具状态 |
| `toolCategory` | enum? | 只记录类别，不记录参数和输出 |
| `source` | enum | CLI、IDE 等有限枚举 |
| `occurredAt` | UTC datetime | 必填 |

明确禁止字段：提示词、完整命令、参数、工具输出、完整文件路径、会话文件、Token、Cookie、账号标识、完整 App Server 响应。

## 本地存储

- macOS：UserDefaults、Application Support、团队前缀 App Group；具体新身份待品牌任务确定。
- Windows：`%LocalAppData%/CodexQuotaView` 或 Windows App SDK 推荐隔离目录；最终路径在实现时验证。
- Fixture：只使用合成数据，禁止复制真实用户响应。
