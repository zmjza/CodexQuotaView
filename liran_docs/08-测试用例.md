## 固定视觉比较条件

- 固定 DPI、缩放、窗口尺寸、桌面背景、主题、语言、Fixture、状态和动画时间点。
- 主面板以 `274 pt` 宽和现有生产几何为母版；Windows 采用等效 DIP，并记录实际像素换算。
- 比较范围：主面板、重置页、确认层、设置、Small/Medium Widget、托盘/菜单栏、活动岛主要状态和流体球。
- 视觉阈值不能被单纯调宽测试容差绕过；抗锯齿差异用感知指标，几何差异单独测量。

## 回归门禁

- 不出现第二层整面玻璃、双重圆角或原生矩形 Panel 阴影。
- 不把不可用显示为 0%，不硬编码 PLUS 或固定六张票据。
- 不恢复多任务 Preview。
- 不加入 Debug Mock、自动截图或自动展开生产入口。
- 不把内部构建成功写成 macOS 真机或 Windows 真机通过。
