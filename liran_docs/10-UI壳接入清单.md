# CodexQuotaView UI 壳接入总清单

## 当前阶段

本文件只规划真实项目 UI 壳，不创建业务 UI、不接真实数据。macOS 已有完整生产 UI 和业务代码；后续 UI 阶段应以现有 macOS 生产界面为母版，先完成品牌壳迁移，再建立 Windows 原生壳。

## 2026-08-14 用户决定：跳过独立造壳，直接跨平台移植

用户明确要求“不需要造 UI 壳，本来就是复刻的。直接把 UI 壳照搬过来即可”。

- macOS：当前 QuotaView 稳定生产 UI 就是现成 UI 壳，随品牌迁移直接复用，不再单独创建 Mock/壳工程。
- Windows：在真实 WinUI 3 工程中逐组件移植 macOS 生产 UI，同时接入真实 ViewModel、状态和事件，不先制造独立空壳。
- 本决定已写入第一次 goal；原 `ui-shells/*.md` 保留作为视觉母版事实来源和移植检查清单。

## UI 壳列表

| 壳 | macOS 事实来源 | Windows 目标 | 数据/状态入口 |
|---|---|---|---|
| 主面板 | `QuotaViewFigmaMenu.swift`、`MenuBarPanelController.swift` | WinUI 浮层/托盘面板 | 套餐、额度、Spark、Token、连接、刷新 |
| 重置流程 | `QuotaViewFigmaResetMenu.swift`、`MenuBarView.swift` | 同尺寸语义的 WinUI 页面/确认层 | 次数、Demo、返回、确认、禁用 |
| 设置 | `SettingsView.swift`、`AppPreferences.swift` | WinUI Settings Window | 主题、语言、可见项、Hook、更新 |
| Widget | `QuotaViewWidget.swift` | Widget Provider 或 Compact Host | 版本化 Widget Snapshot |
| 活动岛 | `CodexActivityIsland.swift` | Windows 顶部浮层等价壳 | 稳定活动状态与流体球 |
| 系统入口 | macOS Status Item | Windows NotifyIcon | 图标、剩余额度/倒计时、菜单命令 |

## 接入硬门禁

1. 后续造壳前读取对应 `ui-shells/*.md`、`AGENTS.md`、避坑知识库和生产源码。
2. 视觉事实优先级：macOS 当前生产代码和固定资源 > 已接受规格 > design-qa/Figma 历史。
3. Windows 壳不使用网页、Electron 或通用营销布局。
4. 壳阶段只使用合成 Fixture，不读取真实凭据，不调用真实消费接口。
5. 必须预留 available/refreshing/unavailable/error、主题、语言、Reduce Motion、键盘和辅助功能入口。
6. 后续 UI 路线选择完成前，不预创建 Windows 业务文件或修改现有 macOS UI。
7. UI 壳接收检查必须核对允许文件、依赖、入口、状态、视觉和接口锚点；未通过不能进入业务接线。
