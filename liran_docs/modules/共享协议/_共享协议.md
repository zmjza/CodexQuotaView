# 共享协议模块

## `CQV-TASK-PROTO-001` 定义共享 JSON Schema
- Requirement：`CQV-DATA-001..010`、`CQV-PRIV-002`。平台：共享。目标：为快照、窗口、Token、错误定义版本化 Schema。
- 前置：DOC-001。读取：`CodexModels.swift`、`DomainModels.swift`、Widget Contract。预计修改：`Shared/Schemas`。
- 步骤：提取真实字段；区分缺失和零；限制大小/枚举；定义版本兼容。禁止：复制完整真实响应。
- 测试：Schema 正反 Fixture。证据：校验报告。回退：提升 Schema 版本而非静默破坏。状态：待开发。

## `CQV-TASK-PROTO-002` 建立脱敏 Fixture
- Requirement：`CQV-DATA-001..010`、`CQV-PRIV-001..003`。平台：共享。目标：覆盖正常、警告、耗尽、离线、错误和边界数据。
- 前置：PROTO-001。读取：现有 Swift 测试。预计修改：`Shared/Fixtures`。
- 步骤：合成套餐、主周期、Spark、Credits、Token 日桶；加入未知枚举、超时和局部失败。禁止：使用真实账号或响应。
- 测试：敏感模式扫描、Schema 校验。证据：Fixture 清单。回退：删除不合规 Fixture 并轮换暴露内容。状态：待开发。

## `CQV-TASK-PROTO-003` 定义状态映射
- Requirement：`CQV-DATA-009`、`CQV-UX-005`。平台：共享。目标：冻结 availability、health、risk、connection 与 UI 状态关系。
- 前置：PROTO-001。读取：`CodexProviderAdapter.swift`、`CurrentCodexPresentation.swift`。预计修改：共享映射文档和双端实现。
- 步骤：记录优先级和不可用占位；保证连接状态不等于额度风险。禁止：错误时伪造零值。
- 测试：表驱动状态矩阵。证据：跨端结果。回退：恢复上一个 Schema 版本。状态：待开发。

## `CQV-TASK-PROTO-005` 双端标准化输出测试

## `CQV-TASK-PROTO-006` 建立协议变更门禁
- Requirement：`CQV-CI-001`。平台：共享。目标：Schema、Fixture、Token 变更需版本和回归。
- 前置：PROTO-005。读取：GitHub workflow。预计修改：CI、PR 模板、协议说明。
- 步骤：检测破坏性 diff；要求兼容说明；上传差异。禁止：无版本直接删除字段。
- 测试：模拟破坏变更应失败。证据：负面 CI。回退：恢复 Schema。状态：待开发。
