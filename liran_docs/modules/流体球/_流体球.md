# 流体球模块

## `CQV-TASK-ORB-001` 盘点 Metal 母版状态
- Requirement：`CQV-HOOK-002`、`CQV-VIS-003`。平台：macOS/共享。目标：提取稳定流体球状态、Uniform、颜色、节奏和降级。
- 前置：VIS-001。读取：`CodexActivityIsland.swift` Metal 代码和 Reducer。预计修改：渲染规格与 Fixture。
- 步骤：列每状态参数和动画时间；区分业务状态与渲染参数。禁止：纳入多任务 Preview。
- 测试：Metal 离屏帧。证据：状态图谱。回退：以生产代码校正。状态：待开发。

## `CQV-TASK-ORB-002` 抽取跨平台渲染输入
- Requirement：`CQV-VIS-003`。平台：共享。目标：定义与 API 无关的 OrbRenderState。
- 前置：ORB-001、PROTO-004。读取：Metal Uniform。预计修改：Schema/Fixture。
- 步骤：位置、时间、能量、颜色、噪声和 Reduce Motion；固定随机种子。禁止：共享 GPU 二进制或 Rust FFI。
- 测试：Schema 与确定性。证据：输入 Fixture。回退：版本化参数。状态：待开发。

## `CQV-TASK-ORB-003` 保持 macOS Metal 实现
- Requirement：`CQV-MAC-004`、`CQV-VIS-003`。平台：macOS。目标：品牌迁移不改变已验证 Metal 视觉。
- 前置：MAC-001、ORB-002。读取：Activity Island。预计修改：命名、测试入口。
- 步骤：TDD 保持 Uniform；适配新资源；离屏捕获。禁止：无理由重写 Shader。
- 测试：关键帧与性能。证据：母版帧。回退：恢复上游 Shader。状态：待开发。

## `CQV-TASK-ORB-004` 实现 D3D11/HLSL 渲染组件
- Requirement：`CQV-WIN-003`、`CQV-VIS-003`。平台：Windows。目标：C++/WinRT 组件消费 OrbRenderState 并输出等价帧。
- 前置：WIN-001、ORB-002。读取：Metal 算法和 HLSL 工具链。预计修改：Rendering 项目、Shader。
- 步骤：端口坐标/噪声/混合；处理色彩空间；设备丢失恢复；WinUI 互操作。禁止：CPU 位图逐帧模拟。
- 测试：HLSL 编译、离屏帧、设备丢失。证据：帧和日志。回退：静态状态图但不得宣称动态达标。状态：待开发。

## `CQV-TASK-ORB-005` 流体球跨平台相似度
- Requirement：`CQV-VIS-003`。平台：双平台。目标：主要状态关键帧感知相似度 ≥90%。
- 前置：ORB-003、004。读取：固定 Fixture。预计修改：视觉测试。
- 步骤：同分辨率/时间/种子；比较轮廓、能量、色彩和运动；输出热图。禁止：只选最相似单帧。
- 测试：每状态多关键帧。证据：报告。回退：调 HLSL 参数而非改母版。状态：待开发。

## `CQV-TASK-ORB-006` 性能与 Reduce Motion
- Requirement：`CQV-UX-005`、`CQV-VIS-003`。平台：双平台。目标：流畅且系统减少动态时降级。
- 前置：ORB-003..005。读取：平台功耗/动画设置。预计修改：帧率和静态策略。
- 步骤：记录 CPU/GPU/内存；非活动降帧；Reduce Motion 静态或低运动。禁止：后台持续满帧。
- 测试：性能基准和状态切换。证据：指标。回退：降低采样频率。状态：待开发。
