- 前置：PROTO-004。读取：AGENTS、主面板/设置/重置/Widget/Activity 源码与资源。预计修改：Visual Token 和 Golden 规范。

- 测试：Token 与代码审查。证据：来源映射。回退：以生产代码为准修正文档。状态：待开发。

## `CQV-TASK-VIS-003` 静态相似度门禁
- Requirement：`CQV-VIS-002`。平台：Windows 对 macOS。目标：主要页面感知相似度 ≥95%。
- 前置：VIS-002、各 UI 壳。读取：Golden。预计修改：差异工具和 CI。
- 步骤：像素与感知双指标；屏蔽系统不可控区；输出热图。禁止：通过扩大遮罩或容差掩盖结构差异。
- 测试：故意位移/改色应失败。证据：CI 报告。回退：回到最后通过 Golden。状态：待开发。
