# 设置与本地化模块

## `CQV-TASK-SET-001` 迁移设置模型与默认值
- Requirement：`CQV-UX-003..004`。平台：双平台。目标：可见指标、刷新、活动、Widget、主题、语言和更新设置一致。
- 前置：PROTO-003、MAC/WIN Shell。读取：AppPreferences、SettingsView。预计修改：双端 Preferences。
- 步骤：列 Key/默认值；迁移旧 macOS 设置；Windows 使用版本化本地设置。禁止：静默丢失现有用户偏好。
- 测试：默认、持久化、迁移、损坏。证据：单测。回退：安全默认。状态：待开发。

## `CQV-TASK-SET-002` 浅色/深色/跟随系统
- Requirement：`CQV-UX-003`。平台：双平台。目标：外观切换不重建业务状态或丢路由。

- 测试：状态保持、截图。证据：主题矩阵。回退：跟随系统。状态：待开发。

## `CQV-TASK-SET-003` 清透/磨砂模式
- Requirement：`CQV-MAC-003`、`CQV-VIS-005`。平台：双平台。目标：用户可选材质并按平台稳定应用。
- 前置：MAC-004、VIS-005、SET-001。读取：GlassMode。预计修改：设置控件和材质服务。
- 步骤：清透/磨砂；隐藏面板延迟应用；Windows 记录等价材质。禁止：增加第二层整面玻璃。
- 测试：显示/隐藏切换、多开。证据：关键帧。回退：磨砂稳定路径。状态：待开发。

## `CQV-TASK-SET-004` 中英文与跟随系统
- Requirement：`CQV-UX-004`、`CQV-BRAND-001`。平台：双平台。目标：所有可见、Tooltip、错误和辅助功能文案即时切换。
- 前置：BRAND-001、SET-001。读取：AppCopy、xcstrings、Windows resources。预计修改：本地化资源。
- 步骤：建立 Key 对照；替换品牌；测试复数/时间；跟随系统禁用手动。禁止：硬裁切英文或漏翻译。
- 测试：Key 完整性、伪本地化、截图。证据：语言矩阵。回退：英文安全文本。状态：待开发。
