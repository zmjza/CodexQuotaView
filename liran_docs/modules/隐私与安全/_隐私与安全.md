# 隐私与安全模块

## `CQV-TASK-PRIV-001` 数据流威胁建模
- Requirement：`CQV-PRIV-001..004`。平台：双平台。目标：列 Codex 进程、App、Hook、Widget、更新和日志边界。
- 前置：PROTO-001、架构文档。读取：现有代码和目标架构。预计修改：安全规格。
- 步骤：标资产/入口/信任边界；识别凭据、路径、响应风险；给出控制。禁止：把假设写成漏洞事实。
- 测试：安全评审清单。证据：威胁模型。回退：缩小接口暴露。状态：待开发。

## `CQV-TASK-PRIV-002` 凭据与网页抓取禁止门禁
- Requirement：`CQV-PRIV-001`。平台：双平台。目标：代码不读取/复制 `~/.codex` 凭据，不抓网页。
- 前置：PRIV-001。读取：所有 I/O 和网络调用。预计修改：静态检查、测试。
- 步骤：白名单官方本地 app-server；扫描凭据路径和浏览器 Cookie API。禁止：用“兼容性”绕过。
- 测试：静态扫描和 fake filesystem。证据：报告。回退：禁用违规 Backend。状态：待开发。

## `CQV-TASK-PRIV-003` 日志与错误脱敏
- Requirement：`CQV-PRIV-002`。平台：双平台。目标：日志不含 Token、Cookie、账号、完整响应、命令参数和完整路径。
- 前置：PRIV-001。读取：日志/错误路径。预计修改：Sanitizer 与测试。
- 步骤：错误码优先；路径只保留末级；截断长度；生产关闭载荷 dump。禁止：完整敏感日志进 Artifact。
- 测试：注入敏感 Fixture 后扫描。证据：脱敏快照。回退：只输出通用错误。状态：待开发。

## `CQV-TASK-PRIV-004` Hook IPC 安全
- Requirement：`CQV-PRIV-003`、`CQV-HOOK-001`。平台：双平台。目标：白名单、认证、用户范围、大小和重放控制。
- 前置：HOOK-001..004。读取：IPC 实现。预计修改：校验器。
- 步骤：版本/认证/时间窗/nonce；拒绝未知字段；有界队列。禁止：全局可写端点。
- 测试：重放、伪造、超大、跨用户。证据：负面测试。回退：关闭 Hook。状态：待开发。

## `CQV-TASK-PRIV-005` 本地存储生命周期
- Requirement：`CQV-PRIV-004`。平台：双平台。目标：设置、快照、队列和缓存位于标准目录并可安全清理。
- 前置：PRIV-001、WIDGET/HOOK。读取：现有路径和 Windows LocalAppData。预计修改：Storage service。
- 步骤：定义权限、TTL、原子写、损坏恢复、卸载边界。禁止：写工作区或全局临时目录长期保存。
- 测试：权限、损坏、清理。证据：路径矩阵。回退：内存态。状态：待开发。
