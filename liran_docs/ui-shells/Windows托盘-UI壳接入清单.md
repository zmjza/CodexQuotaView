# Windows 托盘 UI 壳接入清单

## 目标

建立 Windows 11 系统托盘入口，提供与 macOS 菜单栏相同的快速可达性，但遵循 Windows NotifyIcon、任务栏、多屏和键盘语义。

## 结构

- 托盘图标：深浅任务栏可读，状态变化不滥用颜色。
- Tooltip：CodexQuotaView、剩余额度或连接状态的本地化摘要。
- 左键：打开/关闭主面板。
- 右键：刷新、打开 Codex、设置、Widget、退出；具体项以生产功能为准。
- 单实例：再次启动聚焦现有实例。

## 数据与状态

- 使用同一 Windows Store/ViewModel，不自行刷新。
- 支持有效、刷新中、不可用、错误；托盘入口不能因用户隐藏文字而消失。
- 多屏定位以当前触发点所在屏幕为准，边缘保持安全间距。

## 门禁

- 不模拟 macOS 状态栏原生间距；复刻的是品牌、信息密度和面板体验。
- 键盘菜单、Narrator 名称、Explorer 重启后的图标恢复必须测试。
- EXE 烟雾至少证明托盘创建和可优雅退出。
